Parking Management System

Is a simple Parking Management System developed using HTML, CSS, and JavaScript. The project allows users to register and manage parked vehicles using their licence plate numbers.

Main Features
Register and remove vehicles.
Check parked vehicles.
Save data using Local Storage.
Simple and user-friendly interface.
Manager Code

The project also includes a Manager Code that allows authorised users to access the management form. The code works as a simple access control, helping prevent regular users from accessing the manager area.

Technologies
HTML5
CSS3
JavaScript
Local Storage
